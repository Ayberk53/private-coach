# 🎯 Personal Coach & Productivity Hub — Özel Koçluk ve Verimlilik Paneli

**Personal Coach**, öğrencilerin ve geliştiricilerin günlük çalışma rutinlerini planlamaları, Pomodoro tekniğiyle odaklanma seansları yönetmeleri ve hedeflerini disiplinli şekilde takip etmeleri için geliştirilmiş kişisel koçluk arayüzüdür.

## 🚀 Öne Çıkan Özellikler
* **Odaklanma Zamanlayıcısı (Pomodoro):** Çalışma ve mola periyotlarını yöneten interaktif geri sayım sayacı.
* **Alışkanlık ve Görev Takibi (Habit & Task Tracker):** Günlük/haftalık hedeflerin tamamlanma durumunu takip etme ve ilerleme kontrolü.
* **Planlama Arayüzü:** Kişisel gelişim ve ders çalışma hedeflerini tek bir merkezden organize etme.
* **Kalıcı Veri Saklama:** Tarayıcı kapanıp açılsa bile kullanıcı ilerlemesini koruyan yerel depolama yapısı.

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+) / React
* **Veri Yönetimi:** DOM Manipulation & Web Storage API (`localStorage`)
